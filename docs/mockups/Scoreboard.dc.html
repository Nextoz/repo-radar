Does the radar beat GitHub Trending?

Every live alert is stored with the time it was issued. GitHub Trending is checked on every collector run. This page compares the two, counts the misses, and says plainly what is not known yet.

How to read these numbers

  • Only repos that later reach Trending can have a lead time. An alert for a repo that never trends is not a failure, just unknown.
  • Trending is checked hours apart. A lead time is known only to within one gap between checks, so it is shown as a range.
  • Young histories are weaker. Repos watched for less than 7 days are compared with their lifetime average. Results for the two kinds are shown apart.
  • Replays are not evidence. Flags computed afterwards from old snapshots are listed separately and never count.
